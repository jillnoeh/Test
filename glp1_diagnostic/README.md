# GLP-1 Size Curve Risk Diagnostic

A Streamlit app that scores an apparel retailer's exposure to GLP-1-driven size-curve shifts using only their public website plus proprietary GLP-1 adoption data.

Paste a URL → the app scrapes size availability, clearance, stockouts, and store locations → joins them to bundled GLP-1 datasets → returns a single 0–100 risk score, four component scores, a store-footprint map, a size-gap chart, and ready-to-paste key findings.

## Install

```bash
cd glp1_diagnostic
pip install -r requirements.txt
playwright install chromium    # only needed for JS-heavy retailer sites
```

## Run

```bash
streamlit run app.py
```

Then open <http://localhost:8501>.

If you don't have a target URL handy, click one of the **Sample retailer** buttons in the input panel — three bundled fixtures cover Moderate, High, and Critical risk profiles.

## How it scores

Four components, equal-weighted, each 0–100 (higher = more exposed):

| Component | What it measures |
| --- | --- |
| Geographic Exposure | Store footprint weighted by local GLP-1 adoption (ZIP-level join, DMA fallback). Concentration bonus when >40% of stores sit in top-quartile-adoption ZIPs. |
| Size Range Gap | Sum of positive (projected − offered) gaps across sizes XS–3X+. Demand curve is derived from the consumer panel. |
| Markdown Signal | % of clearance SKUs in L/XL/1X/2X/3X+ minus the same share in the full assortment. |
| Stockout Signal | XS/S/M out-of-stock rate (low-stock counted at half) minus the rest of the assortment. |

Tier labels: **0–24 Low · 25–49 Moderate · 50–74 High · 75–100 Critical**.

To adjust weights, edit `DEFAULT_WEIGHTS` in `scoring/risk_model.py`.

## Swapping in real data

The app reads four CSVs from `data/`:

- `glp1_adoption_by_dma.csv` — `dma_code, dma_name, state, lat, lon, adoption_rate, household_count`
- `glp1_adoption_by_zip.csv` — `zip, city, state, lat, lon, dma_code, adoption_rate, population`
- `glp1_consumer_panel.csv` — `panelist_id, age_band, region, category, months_on_glp1, pre_glp1_size, post_glp1_size`
- `size_demand_curve.csv` — `size, baseline_share, projected_share, delta`

Replace any of these in place; schemas are stable. The bundled files were generated by `data/_generate_sample_data.py` (seed = 7) and contain realistic dummy data, not real adoption figures.

## Scraping behavior

`scraper.scrape(url)` tries:

1. Static HTML via `requests` + BeautifulSoup (Shopify variant JSON, JSON-LD `Product`, size-button DOM).
2. If <10 SKUs or <3 stores found, escalates to Playwright (headless Chromium).
3. If still thin, returns a bundled demo fixture and surfaces a discreet "Demo data" banner in the UI so it's clear the diagnostic is illustrative.

Polite defaults: 10s timeout, 1 req/sec, custom UA.
